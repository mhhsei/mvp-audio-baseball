# MVP Audio Baseball（無障礙 3D 空間音訊棒球）

專為視障朋友（NVDA 螢幕報讀器）與棒球愛好者打造的 3D 空間音訊棒球遊戲，Windows 免安裝綠色版。

## 下載與安裝

1. 前往本頁右側或下方 **[Releases (最新版本)](https://github.com/mhhsei/mvp-audio-baseball/releases/latest)**。
2. 下載 `MVP_Audio_Baseball_vX.Y.Z_Portable.zip` 整包免安裝版並解壓縮。
3. 執行資料夾內的 **`開始遊戲.bat`**（或 `MVP_Baseball.exe`）即可開始遊玩。

## 自動更新

遊戲內建全自動差量更新系統：
- 開啟遊戲進入主選單時會自動偵測新版本（亦可隨時在主選單按 **`U`** 鍵手動檢查）。
- 有新版時 NVDA 會主動語音提示，按 **`Enter`** 即可自動下載變動檔案（`MVP_Baseball.pck`、`MVP_Baseball.exe`、`.dll`、操作說明書等），校驗安全無誤後自動重啟，**絕不會覆蓋您的個人設定（`data/settings.json`）**。
